# 密钥与重置手册（公开仓库里的模板：只写有哪些钥匙、做什么用、怎么重设）

这是公开仓库里的简版。**带日期的真实记录（谁在哪天建的、账号、编号、修改记录）只在私有仓库 `dylan-zhang-wl/frontier-daily` 的同名文件里**，这里不写任何账号邮箱、账号编号、项目编号，也不写任何钥匙的值。

几个词：
- **Secret（仓库密钥）**：存在 GitHub 仓库设置里的钥匙，存进去以后谁都读不出来（包括你自己），只能覆盖。
- **Variable（仓库变量）**：不是秘密的设置，网页上看得到。
- **细粒度令牌**：只对指定仓库、指定权限有效的 GitHub 令牌。

## 规矩

1. 值只由你本人粘贴进终端（`gh secret set 名字 -R <仓库>`，会提示你粘贴，屏幕上不显示），不写进任何文件，不发进聊天。agent 只核对"名字在不在"：`gh secret list -R <仓库>`。
2. "只显示一次"的钥匙不用另外备份：丢了就新建一个、用同一个名字覆盖，再把旧的作废。
3. 新增、重设、作废任何一把钥匙，都在**私有仓库**那份手册里补一行，写上日期。

## 两个仓库各放哪些

| 名字 | 放在哪 | 做什么用 | 丢了或失效怎么重设 |
|---|---|---|---|
| `CLAUDE_CODE_OAUTH_TOKEN` | 公开仓库；私有仓库另有一份（读者反馈初看用） | 云端用 Claude 订阅：选题到改稿、视频导演、审片 | 本机运行 `claude setup-token`，复制新令牌，`gh secret set CLAUDE_CODE_OAUTH_TOKEN -R <仓库>` |
| `MIMO_API_KEY`、`MIMO_BASE_URL` | 公开仓库 | 事件卡（摘事实）和备用声音；地址不算秘密 | 从你本机的 `.env` 直接导入（命令见私有仓库的手册），值不经人手 |
| `STATE_REPO_TOKEN` | 公开仓库 | 细粒度令牌，只对私有仓库有效：Contents 读写（取 `测试版/` 和音乐、存回文字、传文件包到发行版）、Actions 读写（叫私有仓库的"配图""放行发布"） | GitHub 网页 → Settings → Developer settings → Fine-grained tokens 新建同样权限的令牌，`gh secret set STATE_REPO_TOKEN -R <公开仓库>`，再删掉旧令牌 |
| `CLOUDFLARE_API_TOKEN`、`CLOUDFLARE_ACCOUNT_ID` | 私有仓库 | 发布网站、部署保底触发器；账号编号不算秘密，但不写进公开仓库 | Cloudflare 网页 → My Profile → API Tokens，Roll 或新建（模板 Edit Cloudflare Workers，范围只给 wenlongzhang.com 所在的账号和这个域名），只复制令牌那一串再 `gh secret set` |
| `SENDER_EMAIL`、`NOTIFY_EMAIL`、`EMAIL_APP_PASSWORD` | 私有仓库 | 出错邮件：发信邮箱、收信邮箱、发信邮箱的"应用专用密码"（不是登录密码） | 应用专用密码在 Google 账号的"应用专用密码"页删掉旧的、新建一个再 `gh secret set`；改了发信邮箱的登录密码，旧的应用专用密码会全部作废 |
| `CODEX_AUTH_JSON` | 私有仓库 | 私有仓库"配图"流程用 ChatGPT 订阅画图的登录种子；平时用缓存里上次续过的那份（缓存名前缀 `codex-auth-`），缓存没有才用它 | 在本机一个单独的文件夹里重新登录 Codex，把那份登录文件的内容 `gh secret set`（步骤见私有仓库的手册）；云端登录失效时出错邮件会提醒 |
| `GH_DISPATCH_TOKEN` | 私有仓库（也写进两个 Cloudflare Worker 的机密变量） | 细粒度令牌，只有 Actions 读写：保底触发器每天叫公开仓库的出刊流程；网站的读者反馈叫私有仓库的反馈流程 | 新建同样权限、同样仓库范围的令牌，`gh secret set GH_DISPATCH_TOKEN -R <私有仓库>`，再运行"保底触发器"（deploy）和"读者反馈设置"（put）把新值写进 Worker |
| `STATS_KEY_HASH` | 私有仓库 | 站长钥匙的指纹（SHA-256，不是钥匙本身），网站用它认站长 | 本机算好新钥匙的指纹再 `gh secret set`，运行"访问统计设置"（put） |

仓库变量（不是秘密）：

| 名字 | 放在哪 | 做什么用 |
|---|---|---|
| `GCP_WIF_PROVIDER`、`GCP_SERVICE_ACCOUNT` | 公开仓库（私有仓库的旧流程也有一份） | Gemini 配音身份：GitHub 给的身份证明换一小时的 Google 令牌，不存长期密钥 |
| `FD_WRITE_EFFORT`、`FD_DIRECTOR_EFFORT` | 公开仓库 | 写稿、视频导演的思考强度（空＝默认） |
| `SITE_DEPLOY_ENABLED` | 私有仓库 | 发布总开关：`true` 才真发布 |

## Google Cloud 那边（没有密钥，只有一条登记规则）

frontier-daily 项目里有一个身份池 `github`，登记规则只认指定的 GitHub 仓库；服务账号 `frontier-tts` 只有"调用 Vertex AI"一个权限。没有会过期、会丢的东西。要放行或撤掉某个仓库，用主账号运行 `gcloud iam workload-identity-pools providers update-oidc …`（完整命令在私有仓库的手册里）。

另有一个 Google Cloud 项目任何环节都不许用，程序每次配音前会拦（`pipeline/tts_engines.py` 的 `FORBIDDEN_PROJECTS`，不许改松）。
