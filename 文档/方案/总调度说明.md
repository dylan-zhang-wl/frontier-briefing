# 总调度（`fd`）说明

2026-11-02 凌晨写（第 6 批的第一部分）。`fd` 是项目根目录的一个小程序：**一条命令把一期从抓取跑到报告，每一步都有检查、能单独重跑；做过的自动跳过，停在哪就从哪接着跑。**

- 程序在 `pipeline/orchestrator/`，只用 Python 自带的库，所以环境坏了 `./fd doctor` 也照样能跑、能告诉你缺什么。
- 各步真正干活的仍是原来的脚本（`fetch.py`、`run_mimo.py`、`tts.py`、`build_v3.py`……），`fd` 只负责按顺序调用、判断过没过、记账、写报告。**原有脚本、配置一个字没改。**
- 这一版里，要模型写的几步（选题、写稿、审读、改稿）和配图是"半自动"：产出已在就检查一遍、接着跑；不在就停下，告诉你在会话里做什么、写到哪。真正让 `claude -p` 自动写，见第九节。

## 一、怎么用

在项目根目录（`frontier-daily/`）里：

| 想做什么 | 命令 |
|---|---|
| 体检：软件、登录、密钥在不在 | `./fd doctor` |
| 先看看要做什么、要花多少钱（不动任何文件） | `./fd run --date 2026-11-02 --dry-run` |
| 跑一期 | `./fd run --date 2026-11-02` |
| 看这一期每一步的状态 | `./fd status --date 2026-11-02` |

`fd run` 的选项：

| 选项 | 意思 |
|---|---|
| `--until 视频` | 跑到这一步为止。步骤可以写编号（14）、英文键（video）或中文名（视频） |
| `--from 网页` | 从这一步开始，前面的步骤不查 |
| `--redo web,video` | 强制重做这几步（产出在也重做；配音重做时缓存里有的仍不花钱） |
| `--dry-run` | 只列出每一步要做什么、哪些会跳过、估计花多少钱 |
| `--offline` | 只用缓存，不联网，预算 0（测试用） |
| `--budget-usd 0.6` | 这一期 Gemini 配音最多花多少美元（默认 0.6） |
| `--issue-dir 目录` | 指定期目录（默认 `测试版/<日期>`），测试时指向副本；用了它，事件库、账本默认也放在副本旁边，不碰正式的 |
| `--edition sunday_dialog` | 指定版别（默认按星期几：周一到周五工作日、周六深度、周日深谈；11-14 起周六停刊，程序待改） |
| `--lenient` | 网页上的数字核不上时，去掉那几项照常出（最后一级兜底） |
| `--skip-images` | 缺配图不等：网页用程序画的主题色封面，视频那几块不带图 |
| `--use-backup` | 配音直接用 MiMo 备用声音 |
| `--no-preview` | 视频不录预览 MP4（省两三分钟） |
| `--verbose` | 把各步程序的输出全打在屏幕上（默认只写进 `logs/`） |
| `--db`、`--ledger-dir` | 换事件库、账本目录（测试用） |

**每次跑完都会写 `<期目录>/00_调度报告.md`**，先看它：开头写这一期齐不齐、少了什么、要你做什么，再列每一步、提醒和花费。

## 三、每一步怎么判过没过、没过怎么办

照 `文档/经验/检查清单.yaml` 写。"重做"指把问题交回做这一步的人或模型；这一版里要模型做的步骤都是你在会话里做，所以"重做"就是停下来、把问题清单写给你。

| 步 | 怎么判 | 没过怎么办 |
|---|---|---|
| 1 抓取 | raw.jsonl 有条目；列出失败的来源；总条数少于 150 提醒；AINews 社交信号为 0 时分清原因：窗口内没出新一期只在说明里写一句，抓到新一期却拆出 0 条才提醒"可能改版了"（11-03 补） | 单个来源失败：脚本已自动重试一次，再不行跳过（照常出刊）；整次失败再跑一次，还不行停。离线时没有材料就停。同一天定时抓取正在跑时不重复起跑 |
| 2 粗筛归并 | 有候选事件；少于 20 个提醒 | 再跑一次，还不行停 |
| 3 入库 | 批次文件写成 | 再跑一次；还不行只提醒、照常往下（周末汇总会少这一天） |
| 4 选题 | `run_mimo.py check` 全部通过（11-03 起含今日一词：近 30 天讲过的要标 `repeat_of`，中文名沿用往期或 `prompts/术语定名.json`） | 第一次没过：停，把问题交回；**改过一次**还不过、而且只剩条数、比例、今日一词这类软规则：放宽、照常往下（今日一词第 7 步还会查稿子）；其余停下来叫人 |
| 5 事件卡 | 逐字核对（脚本自带，找不到原文的条目自动删）；选题里每条都有卡；一条事实都没通过的卡提醒"降为快讯或换题" | MiMo 出错再跑一次，还不行停（备用 Claude Sonnet 还没接）。离线时不能做卡 |
| 6 写稿 | 三份都在，两份 JSON 能读 | 缺哪份就停，说清用哪份指令、写到哪 |
| 7 稿子检查 | 读音表、`script_check`、周末规则、视频分镜（事实、数字、触发词、旁白禁用说法、3 分钟）、网页数字预检、今日一词（和近 30 天重复时要有 `repeat_of`、播客点明哪天讲过、中文名沿用往期；周末名词解释只提醒）；开场、收尾、速览和小结卡里的易歧义词（只提醒，不算要改，11-09 加） | 读音能改的自动改（改前备份在 `logs/改前备份/`）；第一次有"要改"：停，交回主笔；**改过一次**还只差长短：放宽，配音时也不再按时长拦；数字、引语、禁用说法、分镜核不上：停下来叫人 |
| 8 审读 | `审读意见.md` 在；第一行写"必须改：N" | 不在就停，说清怎么审 |
| 9 改稿 | 必须改为 0 直接过；否则要有 `审读处理*.md`，改后再过一遍第 7 步 | 同第 7 步 |
| 10 配图 | 网页要的图（日卡、今日一词、头条、要闻、深度）和视频要生成的图都在 | 停下等你生成；加 `--skip-images`（离线时自动）就用程序画的封面 |
| 11 配音 | 配音程序自己的对稿、音高、音色、句子级找平、语速、时长把关；`fd` 另管钱 | Gemini 出错或超预算：换 MiMo 备用（Shirley、Dylan 自己的复刻）；备用也不行：**这一期出"数据版"**（网页不带播客，报告开头写明）；配音前估的时长不合要求：停，退回写稿（没花钱）；项目是禁用的那个：停，叫人 |
| 12 混音 | 整集 −16 LUFS（±0.7）、真峰值不超过 −1 dBTP | 失败或量出来不合格：网页改挂不带音乐的人声版；没有人声就跳过 |
| 13 网页 | `make_issue_v3` 严格模式（每个数字都在事件卡里）、`build_v3` 成功 | 数字核不上：停，改网页稿；来不及就加 `--lenient` 去掉那几项照常出。组装出错：停 |
| 14 视频 | 先截原文截图（总时长最多 150 秒，硬上限 240 秒）；`video3_build` 成功（这一步预算 0、不生图，配音在第 11 步）；不超过 180 秒 | 截图没成、超时、出错：那一处退回原句摘录，写进提醒，照常组装；组装失败：这一期网页不放视频，照常出；预览 MP4 没录成只提醒。新动效整期不要：`FD_MOTION=off`（只管一次）或项目根 `fd_开关.json` 改成"关"，第 14 步自动重做 |
| 15 再组装 | 页面数据里有视频 | 视频没成：把旧的 `11_视频v3` 改名挪开（留底），网页不放视频 |
| 16 验收 | 三种视图无报错、不横滚、不缺字；上标不单独掉行；"听这一段"从对的时间放；首屏超过 2 MB 提醒 | 任何一项不过：报告写"验收没过，不要发布"（现在本来也不自动发布） |
| 17 报告 | — | — |

## 四、怎么判断"做过了"，怎么接着跑

- 每一步做完，`fd` 在 `<期目录>/logs/fd_state.json` 里记下：状态、说明、用时、日志、**上游文件的内容指纹**（一串由文件内容算出的短码，内容一变它就变）和产出的指纹。
- 下次再跑：
  - 记录是"做完"、产出还在、上游没变 → **跳过**；
  - 程序类的步骤（入库、检查、配音、混音、网页、视频、验收）**上游变了就自动重做**。比如改了稿子，配音会重配——只重配改过的部分，缓存里有的不花钱；
  - 要模型、要花钱的步骤（抓取、选题、事件卡、写稿、审读、改稿、配图、配音），**产出已经在、但 `fd` 没有记录**（比如以前手动跑的、或者你在会话里刚补上的）→ 检查一遍就**采纳**，不重做；
  - 记录是"失败""等人""跳过" → 再试一次。
- 所以接着跑的办法就是**再敲一遍同一条命令**。想让某一步重做：删掉它的产出，或者加 `--redo`。
- `./fd status --date …` 把每一步的状态（没做／做完／失败／跳过／等人／在跑）和原因列出来；等人的步骤下面写着要你做什么。

## 五、稳定性

**锁**
- 同一期同时只许一个 `fd run`；每一步另有一把锁，同一步只许一个在跑。
- 锁文件放在本机 `~/.cache/frontier-daily/locks/`（不进 iCloud），里面写进程号、开始时间、命令、哪台电脑。进程不在了（或进程号被别的程序占了）就当失效、自动清掉。
- 另外起跑前用 `pgrep -f` 查：同一天的抓取、粗筛归并、入库、配音有没有别的进程在跑（比如每天 05:07 的定时抓取），有就不重复起跑。

**账本和月上限**
- 每期一份 `<期目录>/花费.json`，每月一份 `测试版/月度账本/<年-月>.json`，按服务分开记：Gemini、MiMo、Codex、Claude。
- **钱数不自己估**：配音的钱从配音程序写的 `usage.json`（"其中本次新花费美元"）读；那一步中途失败、`usage.json` 没写成时，从配音缓存里这一步期间新写的每条记录（各自记着 `cost_usd`）加起来补记，并注明。MiMo 免费期只记 token；Codex、Claude 走订阅，记 0。
- 月上限读 `pipeline/voice_profile.json` 里建议的 `$8`。**本月 Gemini 已记到 90%（$7.2）就整期改走 MiMo 备用**，报告开头提醒；没到 90% 时，这一期的 Gemini 预算是"`--budget-usd` 减去本期已花"和"上限减去本月已花"里小的那个，再分给播客和视频旁白（视频最多 $0.10）。
- 只有经 `fd` 跑的才进账本：**10-31、11-01 手动跑的和各轮配音测试的花费没记进来**。

**日志**：每一步、每条命令的全部输出（Python 一律 `-u`，边跑边写）在 `<期目录>/logs/<步号>_<步名>_<时间>.log`；屏幕上只显示要紧的几行，加 `--verbose` 才全打出来。

**保底（数据版）**：配音失败、换备用也不行时，网页照常组装，只是不放播客（视频旁白也没配成就不放视频），报告开头写"这一期是保底的数据版，少了……"。没过验收的不发布。

**离线**（`--offline`）：子程序的联网全部指向一个不存在的端口（万一哪段程序想联网会立刻失败），MiMo 读不到密钥，Gemini 预算 0，只能用缓存。专门给测试用。

**冻结的两期**：`测试版/2026-10-31`、`2026-11-01` 不许 `fd` 改（`--dry-run`、`status` 可以）；要试就复制一份，用 `--issue-dir` 指过去。

## 六、半自动的几步：在会话里怎么补

`fd` 停在这几步时，屏幕上和报告里会写"要你做"，照做以后**再敲一遍同一条 `fd run` 命令**就接着跑：

| 步 | 在会话里做什么 | 写到哪 |
|---|---|---|
| 4 选题 | 按 `pipeline/prompts/选题.md`，读 `02_选题/candidates_compact.json` 和 `往期今日一词.json`（周末再读 `本周话题.md`、`留给周日.json` 或 `周日候选.json`） | `02_选题/最终选题.json`、`选题说明.md` |
| 6 写稿 | 按上面"三种版别"那张表的指令，输入 `04_文稿/写稿输入.json`，事实只来自 `03_事件卡/cards_写稿用.json` | 三份稿子 |
| 7、9 稿子检查没过 | 照列出的问题改稿 | 原稿 |
| 8 审读 | **另开**一个只读的 Claude（新会话或子代理），对照事件卡审三份稿子，附上 `文档/经验/问题与解决办法.md` 第二部分"已定规矩"（原第十五节）；第一行写"必须改：N" | `审读意见.md` |

## 八、现有脚本的缺陷（这次只记下，没改）

`fd` 都绕过去了，绕法写在括号里。

1. **`script_check.py --json` 会崩**：结果里有 numpy 的布尔值，`json.dumps` 报 `Object of type bool is not JSON serializable`。（`fd` 用 `orchestrator/helpers.py script-check` 直接调 `script_check.check()`，自己转成 JSON。）
2. **`prefilter.py`、`cluster.py` 只认 `--day`**，输出写死在 `测试版/<日期>/`，副本上跑不了。（和 `event_db.py prep` 同一个办法：在子进程里把 `run_dir` 换成副本目录。）
3. **`run_mimo.py check` 有问题也返回 0**，只把问题打在屏幕上。（`fd` 读屏幕上的"选题自查：N 处"和每行"- …"。）
4. **`podcast_mix.py` 命令行传不了对谈的"声音包调整"**，对谈稿想单独重混只能在 `dialog_tts.py` 里面混。（`helpers.py mix --dialog` 调 `mix_package(overrides=…)`，和 `dialog_tts.py` 读同一份设置；11-01 重混逐字节相同。）
5. **`make_issue_v3.py` 不给 `--out` 时写进代码目录** `site/tools/v3_issues/<日期>.py`，副本、测试也会写过去。（副本一律加 `--out <期目录>/10_网页配置.py`。）
6. **`video3_build.py --stage voice` 是隐藏选项**（帮助里不显示），`fd` 靠它在第 11 步只配视频旁白、不组装。哪天改名了，第 11 步的视频旁白会失败（失败时按保底处理，不会乱花钱）。
7. **`video3_build.py --engine mimo` 在旁白没改时不会重配**，照旧用已有的 Gemini 配音，只打一句"现有配音是旧设置"。所以"到上限改走备用"只对还没配过的旁白起作用。（`fd` 按 `voice.json` 里实际的引擎写报告，不会写错。）
8. **抓取窗口默认值仍按运行日零点**（经验 A2 早就记过）：定时抓取用默认值，05:07 跑时窗口实际约 41 小时。`fd` 自己抓的时候传 `--since`（开跑前 36 小时），但定时抓取已经抓过的，`fd` 直接采纳。
9. **副本不按冻结表定版别**（`run_mimo.py` 的设计，给了 `--run-dir` 就按星期几）。复现 11-01 要加 `--edition sunday_dialog`；`fd` 遇到这种情况会提醒。
10. **11-01 的对谈已经没法用缓存重配**：之后"周日搭档"的乙换成了 Dylan、甲的语气改成固定、加了情绪色板，按现在的设置重配要新花钱。这不算毛病，所以冻结期的配音一律"采纳已有"，只重混、重组装。
11. 小事：`dialog_tts.py` 加 `--no-mix` 时仍要求 `--out`；`build_v3.py` 找不到播客时打印的路径是一长串 `../../`；`video3_images.ensure(gen=False)` 遇到资料图（Commons）仍会联网去取（离线时取不到，照常跳过）。
